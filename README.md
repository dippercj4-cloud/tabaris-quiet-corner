# Tabaris on GitHub Pages

This folder contains the ready-to-publish site. `index.html` is the entry point GitHub Pages looks for.

## Publish it

1. Sign in to GitHub and create a **public** repository, for example `tabaris`.
2. Upload the contents of this folder to the **root** of that repository. The repository root should contain `index.html` (not just a nested `tabaris-github-pages` folder).
3. Commit the uploaded files to the `main` branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/(root)` folder, then click **Save**.
7. Wait for the deployment to finish. GitHub will show the public site URL on the Pages settings screen. It is usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

The page and its embedded images are public once deployed. The diary entries are static page content, not private or access-controlled.
